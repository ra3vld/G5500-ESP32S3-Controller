# Контроллер на мачте — проект KiCad

Откройте `ESP32-S3-ETH-CAM-MAST.kicad_pro` в KiCad 10, затем редактор схем. Схема занимает один лист A2. Локальная библиотека `ESP32-S3-ETH-CAM-MAST.kicad_sym` и таблица `sym-lib-table` входят в проект; установка дополнительных библиотек не нужна. Для просмотра без KiCad используйте одноимённые PDF, SVG или PNG.

Это монтажная схема готовых модулей: Waveshare ESP32-S3-ETH с камерой, два BTS7960, два MT6701 и изолированный RS-485. Обозначения выводов соответствуют сигналам модулей. Внутренние цепи готовых плат не раскрываются. Все внешние соединения, включая питание и общий провод, выполнены линиями. Точки обозначают соединения; пересечения без точки электрически раздельны.

## Подключение

| Назначение | GPIO платы | Подключение |
|---|---|---|
| AZ RPWM / LPWM / ENABLE | 17 / 16 / 6 | A4: RPWM / LPWM / R_EN + L_EN |
| EL RPWM / LPWM / ENABLE | 44 / 43 / 7 | A5: RPWM / LPWM / R_EN + L_EN |
| Общая I²C SDA / SCL | 4 / 5 | Оба MT6701; подтяжки R13/R14 к 3V3 |
| Питание датчиков | 3V3 / GND | Модули MT6701 с питанием 3,3 В и выбранным режимом I²C |
| Камера | Штатный FPC24 | A2, короткий шлейф внутри корпуса |
| Ethernet | Штатный RJ45 | J2, кабель к коммутатору |

GPIO4/5/6/7 доступны на контактах TF1 2/7/3/5 соответственно. Слот microSD оставьте пустым. Используйте BTS7960 с входным буфером HC/AHC244, допускающим питание логики 3,3 В; иной вариант модуля требует согласования уровней. R1–R6 — последовательные резисторы 47 Ом; RN1/RN2 — группы из трёх отдельных резисторов 10 кОм с общим выводом GND. Выходы измерения тока R_IS/L_IS здесь не используются.

На общей шине AZ имеет адрес `0x06`, EL — `0x46`. До объединения датчиков запрограммируйте адрес второго MT6701 совместимым программатором и проверьте его после отключения и включения питания. В настройках контроллера выберите MT6701 на обеих осях, адреса **6** и **70**, SDA=4 и SCL=5. Поле адреса контроллера не программирует энкодер. Учитывайте подтяжки на модулях: все они подключаются только к 3V3. Держите I²C короткой около поворотки.

Подайте на PS1 напряжение двигателей в пределах допустимого для BTS7960 и DC/DC. Номиналы F1/F2 выбирайте по двигателям, F3 — по входному току преобразователя. A3 должен выдавать стабилизированные 5 В с запасом для платы, камеры и Ethernet. Силовые возвраты B− и сигнальные земли соединяйте отдельными ветвями в точке распределения питания; ток двигателей не должен проходить через Waveshare. Перед подключением USB отключите внешний источник 5 В платы.

## Вариант RS-485

A6 — готовый модуль с логикой 3,3 В, гальванической развязкой сигналов **и питания** стороны шины. COM изолированной стороны соединён только с удалённым устройством J4. Локальная GND к COM не подключается. R16 и R17 устанавливаются на физических концах линии; если согласование уже есть в модулях, дополнительные 120 Ом не устанавливайте. Выбирайте трансиверы с гарантированным состоянием при свободной шине либо предусмотрите рассчитанную для выбранных модулей цепь смещения в одном месте линии.

Этот вариант использует GPIO19/20/21 вместо USB и RGB и требует отдельной конфигурации прошивки: штатный `waveshare_esp32s3_eth` резервирует GPIO19/20. Подключайтесь к точкам линий USB D−/D+ по схеме платы, а не к TX/RX GPIO43/44, занятым приводом. Перед USB-прошивкой снимайте JP1–JP3; при работе RS-485 USB-кабель данных отключён. Камера доступна по Ethernet/Wi-Fi, RS-485 передаёт команды и телеметрию. Параметры и протокол удалённого HUD или шлюза должны совпадать с контроллером.
