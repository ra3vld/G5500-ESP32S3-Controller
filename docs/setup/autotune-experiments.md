# Подбор методики автотюна через API

[Документация](../index.md)

Для каждого запуска можно изменить методику измерения через тот же API по USB, UDP, TCP или HTTP. Опции действуют только в текущем запуске, не сохраняются в настройках и не наследуются следующим запуском. Сначала остановите обе оси, отключите удержание и прочитайте идентификатор последней процедуры. Запуск автотюна переведёт контроллер в ручной режим и отменит ожидающие команды:

```sh
python3 tools/controller_api.py --serial /dev/ttyUSB0 GET /api/motion/autotune full=1
python3 tools/controller_api.py --serial /dev/ttyUSB0 POST /api/motion/autotune action=start axis=az mode=cascade id=0 travel=60 outputLimit=50 tuneSearchStartPercent=10 tuneSearchStepPercent=5 tuneWorkingFraction=0.7 tuneLambdaFactor=2
python3 tools/controller_api.py --serial /dev/ttyUSB0 GET /api/motion/autotune full=1
python3 tools/controller_api.py --serial /dev/ttyUSB0 POST /api/motion/autotune action=cancel
```

Замените `id=0` на прочитанный `id`, а `mode` — на сохранённый режим выбранной оси. Идентичный повтор старого запроса новый запуск не создаёт. Для следующей гипотезы отмените или дождитесь завершения текущей процедуры, прочитайте новый `id` и передайте полный набор нужных отличий от значений по умолчанию. В автоматических сценариях передавайте `action=cancel id=…`: отмена с устаревшим идентификатором отклоняется и не затрагивает новый запуск. Отмена без `id` сохраняет обычное действие кнопки «Отменить».

| Поле | По умолчанию | Допустимо | Что изменяет |
|---|---:|---:|---|
| `tuneStages` | 31 (Cascade), 7 (Simple) | 1…31, целая маска | Выбор этапов: 1 — страгивание, 2 — рабочие параметры (включает 1), 4 — минимум, 8 / 16 — малые / высокие скорости серий в каскаде. По умолчанию полный запуск. |
| `tuneSearchStartPercent` | 5 | 1…100, не выше `outputLimit` | Первый постоянный выход поиска страгивания |
| `tuneSearchStepPercent` | 5 | 1…20 | Шаг поиска страгивания и повышения верхнего рабочего уровня, в процентных пунктах |
| `tuneStartupObservationMs` | 500 | 100…2000 | Минимальное наблюдение уровня без движения; фактический интервал также учитывает задержку датчика и ограничен сроком пуска |
| `tunePlateauMinMs` | 200 | 160…1000 | Минимальное окно измерения устойчивой скорости; подтверждается вторым окном |
| `tunePlateauTimeoutMs` | 2500 | 1000…10000 | Срок поиска устойчивого рабочего участка, затем минимальный выход повышается |
| `tuneWorkingFraction` | 0,5 | 0,1…1 | Желаемая доля разрешённого выхода для верхней рабочей точки; сохранённый рабочий процент также учитывается |
| `tuneLambdaFactor` | 1 | 0,5…4 | Множитель времени отклика PI скорости: больше — спокойнее настройка каскада |
| `tunePositionGainFactor` | 1 | 0,25…2 | Множитель предложенного P положения каскада |

`tunePlateauTimeoutMs` должен быть не меньше `2 × tunePlateauMinMs + 200`. Неизвестное поле с префиксом `tune` или неверное значение отклоняет запрос целиком. Ответ `full=1` содержит фактически принятые `options` и версию `options.methodVersion` для сопоставления результатов. Компактные статусы остаются короткими.

Изменение гипотезы не отключает свежесть датчика, контроль другой оси, границы пробного участка, предел выхода, паузу реверса и срок измерения 120 секунд; в каскаде при переходе к подбору серий общий срок запуска составляет до 480 секунд. Длинные окна требуют большего свободного хода; процедура может безопасно отказаться от результата, если он не помещается. Малый `tuneLambdaFactor` и большой `tunePositionGainFactor` увеличивают риск раскачки. После изменения страгивания, рабочего профиля или коэффициентов проверяются наведения в обе стороны; при выбранных этапах слежения каскад также сравнивает варианты на сериях с периодами 200/1500 мс, выбранными скоростями и обоими направлениями. Выбранные коэффициенты повторно проверяются одиночными наведениями; минимум подтверждается повторно, если выбран его поиск; результат применяется отдельным `action=apply id=…`, который сохраняет параметры. Для сравнения гипотез до применения используйте полные ответы с измерениями и предложением; сохранённые настройки восстанавливаются после каждой процедуры.

### Сравнение с записью результатов

Для сравнения создайте файл `variants.json`, например:

```json
{
  "baseline": {
    "axis": "az", "mode": "cascade", "travel": 60, "outputLimit": 50
  },
  "calmer": {
    "axis": "az", "mode": "cascade", "travel": 60, "outputLimit": 50,
    "tuneLambdaFactor": 2, "tunePositionGainFactor": 0.7,
    "tunePlateauMinMs": 400, "tunePlateauTimeoutMs": 4000
  }
}
```

Проверьте файл без подключения, затем запустите один выбранный вариант:

```sh
python3 tools/autotune_experiment.py variants.json calmer --dry-run
python3 tools/autotune_experiment.py --serial /dev/ttyUSB0 --log calmer.jsonl variants.json calmer
```

Запуск приводит ось в движение. Подготовьте свободный участок с запасом на выбег и используйте один источник управления. Параметры `travel` и `outputLimit` задают разрешённый пробный ход и предел выхода. Для следующего варианта верните привод в сопоставимое начальное положение. Вместо USB можно указать `--udp HOST` или `--tcp HOST`.

Утилита записывает исходный вариант, положение, измеренную скорость, выход, фазы и полный итог в новый JSONL-файл. Сравнивайте оба направления, измеренные рабочие скорости, выбег и `validationError`; успешное завершение само по себе не доказывает устойчивость под нагрузкой. Чтение через USB на 9600 бод занимает время, поэтому журнал служит для сравнения проб, а регулятор продолжает работать со своим периодом.

Результат автоматически не применяется. Для сохранения выбранного результата используйте `POST /api/motion/autotune action=apply id=…`, взяв `id` из итога последнего запуска. При Ctrl+C или таймауте утилита пытается отменить свою процедуру; при потере связи отмена может не дойти. Встроенные ограничения пробного хода, выхода и длительности сохраняются. Утилита не меняет настройки защит, калибровку или режим сети.

Скрипт `tools/autotune_experiment.py` по умолчанию ожидает до 510 секунд на запуск, чтобы дождаться подбора серий. Параметр `--duration` задаёт собственный срок ожидания; его истечение отменяет незавершённый запуск. Полный ответ сохраняет оценки вариантов в `tracking.candidates` и номер выбранного варианта в `tracking.selected`.

Для быстрой частичной настройки укажите `tuneStages` в гипотезе: `4` — только минимум, `8` / `16` — одна скорость серий, `24` — обе скорости без идентификации. Фактически выполненная маска возвращается в `options.tuneStages` (`methodVersion=8`). Проверки результата остаются обязательными; повторный минимум после слежения выполняется только при выбранном флаге 4. Подробности — [выбор этапов](regulator-tuning.md#выбор-этапов).
