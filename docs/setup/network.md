# Сеть и порты

[Документация](../index.md)

На новом устройстве используйте [мастер настройки](first-start.md). В обычном интерфейсе раздел **Настройки → Статус сети** открыт по умолчанию и показывает адреса и состояние подключения. Для изменения параметров раскройте **Настройки сети**.

## Адреса IPv4

В **Подключение и IP-адреса** отдельно для Wi-Fi STA и Ethernet выберите DHCP или статический адрес. Для статического подключения нужны IP и маска; шлюз и DNS задаются при необходимости. Сохранение этой формы запускает пробное подключение после перезапуска. Откройте показанный новый адрес через выбранную сеть и нажмите **Подтвердить этот адрес** в течение трёх минут. Пока подтверждения нет, сервисная AP остаётся включённой. По истечении времени устройство возвращает прежние IP-параметры и тип подключения и перезапускается; то же действие можно вызвать кнопкой **Вернуть прежнюю сеть**. SSID и пароли этот откат не меняет. При ошибке записи возврата AP остаётся доступной для исправления. Пароли и SSID задаются в формах ниже.

## Ethernet

На [WT32-ETH01](../boards/wt32-eth01.md) RJ45 включён автоматически; по умолчанию адрес выдаёт DHCP, статический адрес выбирается в сетевых настройках. Веб, API, rotctld, UDP и HUD используют обычные порты из таблицы ниже. Проводной адрес виден как **ETH**; Ethernet имеет приоритет перед Wi-Fi STA. Настройки Wi-Fi и резервная AP сохраняются.

## Подключение Wi-Fi

1. Подключитесь к `G5500-Rotator-XXXXXX` и откройте `http://192.168.4.1`. В роли HUD сеть называется `G5500-HUD-XXXXXX`. У нового устройства AP без пароля; задайте его в настройках.
2. В **Настройки → Настройки сети** укажите SSID/пароль роутера и нажмите **Сохранить и подключиться**. Пустой пароль допустим для открытой сети. В режиме общей AP сначала выберите обычную сеть в **Роль и связь**.
3. Дождитесь «Подключено» и адреса **STA**. Он нужен для доступа через роутер; адрес **AP** — через сеть устройства. Адреса также видны на дисплее и в диагностике; у HUD они относятся к пульту.

Сохранение Wi-Fi применяется без перезапуска. AP остаётся включённой до следующей загрузки; при смене канала телефон может кратковременно отключиться. Если ответ не получен за 12 секунд, переподключитесь, обновите страницу и проверьте сохранённый SSID перед повтором. Ошибка записи настроек не меняет подключение. Смена пароля AP перезапускает устройство.

## Резервная точка доступа

На ESP32, S2 и S3 режим выбирается на странице `/hardware` в поле **Точка доступа**: резервная AP включается при отсутствии настроек или потере сети; постоянная остаётся доступной вместе с сетью роутера. Сохраните и подтвердите изменение оборудования. Во время пробного подключения и в режиме восстановления сервисная AP остаётся включённой при любом выборе. Незавершённый мастер сам по себе не меняет режим AP.

Попытка STA длится до 8 секунд, повтор — через 30 секунд с сохранённой AP. Сохранение SSID ещё не означает успешного подключения. В общей сети HUD хозяин AP держит её включённой. При пересечении подсети роутера с `192.168.4.0/24` устройство при запуске выбирает другой адрес AP; актуальный адрес смотрите на дисплее или через [диагностику](../maintenance/diagnostics.md#нет-доступа).

Если сохранённый пароль AP или адрес мешает подключению, войдите в [восстановление по трём нажатиям Reset](../maintenance/diagnostics.md#вход-в-восстановление-кнопкой-reset). В этом режиме доступна отдельная открытая сеть `G5500-Recovery-XXXXXX`.

## Порты

Значения по умолчанию; изменяемые порты смотрите в настройках или `GET /api/network`.

| Транспорт / порт | Назначение | Настройка |
|---|---|---|
| TCP 80 | Веб и HTTP API | Фиксирован; отсутствует в вариантах `noweb` |
| TCP 81 | WebSocket `/api/live` | Фиксирован; отсутствует в вариантах `noweb` |
| TCP 4533 | GS-232, rotctld и командный API | Фиксирован |
| UDP 4534 | HUD: поиск, команды, состояние | Раздел «Роль и связь» |
| UDP 4535 | Командный API | `commandPort` |
| UDP 12040 | N1MM: приём команд | `n1mmPort` |
| UDP 13010 | N1MM: отправка положения | `reportPort`, получатели и `reportHost` |
| UDP 1234 | PstRotator: приём команд | `pstPort` |
| UDP 1235 | PstRotator: отправка ответа | Всегда `pstPort + 1` на IP отправителя |
| UDP 3232 | ArduinoOTA | Открывается на 10 минут по запросу |
| UDP 5353 | mDNS | Обнаружение сетевого порта ArduinoOTA |

Порты UDP не должны пересекаться; в сборках с вебом также зарезервирован UDP 32769 службы live. Для ArduinoOTA нужна обратная связь ESP32 с TCP-портом отправителя. [Настройка OTA](../maintenance/ota.md).

Веб и команды доступны участникам сети без отдельной авторизации. Используйте доверенную локальную сеть. Далее: [подключение программы](../integrations/index.md), [HUD](../control/hud.md) или [диагностика](../maintenance/diagnostics.md).
