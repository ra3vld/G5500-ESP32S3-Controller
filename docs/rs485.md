# Управление через RS‑485

[Документация](index.md) · [Настройки оборудования](configuration.md#оборудование-в-веб-интерфейсе)

Компьютер может управлять повороткой обычными командами GS‑232 через USB–RS‑485 с автоматическим переключением направления передачи. В программе выберите COM‑порт адаптера, протокол GS‑232 и **9600, 8N1**, без аппаратного управления потоком. Дополнительная программа-мост на компьютере не требуется.

## Компьютер и один контроллер

Подключите трансивер RS‑485 к UART0 контроллера:

| Сигнал трансивера | Подключение к ESP32 |
| --- | --- |
| DI | UART0 TX |
| RO | UART0 RX |
| DE и /RE, соединённые вместе | Назначенный выход `uartDe` |
| Питание и логические уровни | Совместимые с GPIO 3,3 В |

На странице `/hardware` назначьте **UART0 · RX**, **UART0 · TX** и **ПК · RS‑485 DE и /RE**. Выход DE должен быть активным HIGH: LOW включает приём, HIGH — передачу. Сохраните настройки, подтвердите пробный запуск. Для обычного UART оставьте DE равным `−1`.

В настройках роли отключите HUD UART, если отдельного пульта нет. Команды `M`, `W`, `C`, `C2`, `B`, `S` и остальные поддерживаемые [команды GS‑232](integrations.md#usb-bluetooth-tcp) сохраняют своё значение. В ручном режиме внешняя цель может требовать подтверждения; для автоматического выполнения настройте автоследование GS‑232 или автоматический режим.

## Компьютер через HUD

Используйте две электрически независимые линии:

```text
ПК — USB–RS‑485 — линия 1 — HUD — линия 2 — контроллер поворотки
                         UART0   UART1       UART1
                         GS‑232  связь HUD   связь HUD
                         9600    115200      115200
```

На HUD нужны два UART и два трансивера RS‑485. На контроллере нужен один трансивер связи с HUD. Соединять A/B двух линий между собой нельзя.

1. На обоих устройствах в `/hardware` назначьте три сигнала группы **RS‑485 · связь HUD с контроллером (UART1)**: `hudRx`, `hudTx`, `hudDe`. На каждом трансивере соедините DE и /RE с его выходом `hudDe`.
2. На HUD настройте UART0 и `uartDe` для линии компьютера, как описано выше. RX/TX/DE разных портов должны использовать разные GPIO. На контроллере UART0 можно оставить для отдельного подключения или отключить парой RX/TX.
3. Сохраните и подтвердите аппаратные настройки. В настройках роли выберите **HUD — удалённый пульт** для пульта и **Контроллер поворотки** для устройства возле привода. На обоих включите HUD UART. При наличии назначенного UART1 этот переключатель включает именно его.
4. На HUD найдите контроллер по UART, сохраните запись и выберите её. Подробнее: [выбор поворотки](hud.md#выбор-и-управление).
5. Подключите программу на ПК к COM‑порту USB–RS‑485 с параметрами GS‑232, 9600, 8N1.

HUD передаёт команды компьютера выбранному контроллеру и показывает его состояние. Ручное управление с HUD работает одновременно с компьютерным; действуют обычные правила режимов, пресетов и STOP. Опрос положения возвращает последнее актуальное состояние, полученное пультом. При отсутствии связи положение недоступно. Отключение ПК не отключает связь HUD с контроллером.

На второй линии передачу начинает только HUD. Контроллер отвечает на опрос: в ответе может находиться подтверждение команды или состояние. Обе стороны должны использовать прошивку с этим режимом; обычный HUD UART 115200 без трансиверов использует другой формат. На каждой линии поддерживается одна пара устройств.

Для этой схемы подходят любые поддерживаемые платы с двумя доступными UART и достаточным количеством свободных GPIO. Выводы назначаются в веб-интерфейсе. UART1 занят внешним HC‑05, поэтому одновременно использовать HC‑05 и связь HUD по RS‑485 нельзя. Встроенный Bluetooth SPP на классическом ESP32 отдельного UART не занимает. Занятые дисплеем, памятью и другими сигналами GPIO использовать нельзя; штатной CrowPanel не хватает выводов для двух таких портов.

## Кабель и проверка

Используйте витую пару для A/B. Для неизолированных интерфейсов предусмотрите сигнальный общий провод; у изолированных модулей следуйте схеме производителя. Каждую линию согласуйте отдельно: обычно по 120 Ом между A/B на её двух концах. Проверьте уже установленные резисторы и цепи смещения на модулях. Обозначения A/B у производителей могут различаться.

Выбирайте трансиверы с логическими уровнями 3,3 В или подходящим согласованием. Для длинных наружных линий предусмотрите развязку и защиту. На время сброса ESP32 внешний резистор должен удерживать DE в LOW, чтобы передатчик оставался выключенным.

Первую проверку выполняйте при отключённом силовом питании привода: запросите `C2`, затем проверьте STOP и передачу целевого угла. После настройки и калибровки проверьте движение с доступной остановкой. При обрыве линии проверьте индикацию отсутствия связи и прекращение удерживаемого ручного движения. Уже принятая числовая цель может выполняться контроллером автономно.
