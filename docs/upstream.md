# Совместимость и особенности управления

## Выбор оборудования

Плату, дисплей, Bluetooth и силовой интерфейс выбирайте перед сборкой в [build_config.hpp](../G5500_Fork/build_config.hpp). Модель поворотки, диапазон, калибровки, скорости и режим управления задаются через веб.

- Для штатного блока Yaesu используйте `DRIVE_YAESU`. Внешний модуль 0–5 В нужен только для электронного управления скоростью G-800DXA.
- Для независимых приводов используйте `DRIVE_SEPARATE_PWM` или `DRIVE_BTS7960` по выбранной схеме. В BTS7960 выводы скорости служат ENABLE, а PWM идёт на вывод направления.
- На ESP32 доступны встроенный Bluetooth Classic SPP и внешний HC-05; на S2/S3 — внешний HC-05. BLE не поддерживается.
- Обычный профиль CrowPanel работает как [HUD](hud.md) или с имитацией привода. Для переделанной платы профиль [`crowpanel_21_az`](crowpanel-az.md) управляет одной осью AZ через Yaesu G-800DXA либо BTS7960; датчик подключается к освобождённому GPIO6, скорость/ENABLE — через инвертор к BOOT.

Распиновки плат различаются. При переносе проводки сверяйте назначение каждого сигнала с [профилем платы](configuration.md).

## Управление

В ручном режиме внешняя числовая цель по умолчанию требует подтверждения кнопкой или через веб; для каждого протокола можно включить автоследование в настройках. Локальная цель из веба, ручки CrowPanel или предустановки выполняется сразу. STOP останавливает движение, очищает ожидание и последовательность, сохраняя режим. После перезапуска цели не восстанавливаются.

При активной предустановке внешние команды движения отклоняются; STOP и запросы положения доступны. Для G-800DXA используется только азимут, для G-5500 — обе оси. Подробности — в [инструкции управления](usage.md).

У реального привода стандартная зона остановки — ±5°. При входе в неё или пересечении цели ось останавливается; обратной коррекции после перелёта нет. Повтор внешней цели в пределах допуска от последней принятой цели не запускает движение заново. Допуск задаётся при сборке, физическая точность зависит от механики и калибровки. В имитации ось останавливается точно на заданном угле.

Проценты скорости задают уровень управляющего выхода. Скорости старта и подхода, время разгона и торможения подбирайте по реакции поворотки. При ошибке инициализации PWM движение блокируется до перезапуска.

## Программы и интерфейсы

- GS-232: UART0 и выбранный Bluetooth. На CrowPanel также доступен native USB.
- TCP 4533: rotctld и GS-232.
- N1MM Logger+: прямой UDP, стандартный порт команд 12040.
- UR5EQF и 5MContest: PstRotator UDP, стандартные порты 1234/1235.
- Команда GS-232 `Z`, BLE и веб-OTA не поддерживаются. Поддерживаемые команды и параметры API перечислены в [usage.md](usage.md).

Для других логгеров сверяйте используемый транспорт и формат команд. Поддержка приложением программы PstRotator сама по себе не означает совместимость с UDP-интерфейсом контроллера.
