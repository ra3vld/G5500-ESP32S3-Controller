# WT32-ETH01: Ethernet и привод

[Документация](../index.md)

Профиль для Wireless-Tag WT32-ETH01: ESP32, Flash 4 МиБ, PHY LAN8720A. Дисплей не поддерживается; управление — через веб, внешнюю программу, UART или HUD. Имитация и все три силовых интерфейса доступны.

## Сборка и запись

```sh
pio run -e wt32_eth01
pio run -e wt32_eth01 -t upload --upload-port /dev/ttyUSB0
```

Arduino CLI: `./tools/build_arduino.sh wt32-eth01`. В IDE выберите **WT32-ETH01 Ethernet Module**, Flash 4 MB, **Huge APP**, 40 MHz; `BOARD_AUTO` распознаёт плату. [Подробности сборки](../build.md).

Встроенного USB нет. Подключите USB–UART с логикой **3,3 В**: TX адаптера → RX0/GPIO3, RX → TX0/GPIO1, GND → GND. Для записи замкните IO0 на GND, перезапустите через EN, запишите прошивку. Затем снимите перемычку IO0–GND и перезапустите: IO0 нужен тактированию Ethernet. Не используйте для прошивки выводы RXD/GPIO5 и TXD/GPIO17.

Питайте плату через 5V либо 3V3, используя один источник; предусмотрите не менее 500 мА. Силовое питание привода на время записи отключите. Проверьте ревизию и маркировку выводов по [руководству Wireless-Tag](https://files.seeedstudio.com/products/102991455/WT32-ETH01_datasheet_V1.1-%20en.pdf).

## Сеть

1. Подключите RJ45 к роутеру или коммутатору с DHCP. Прошивка запускает Ethernet автоматически.
2. Найдите выданный адрес в списке DHCP роутера. Также можно подключиться к AP `G5500-Rotator-XXXXXX`, открыть `http://192.168.4.1` и посмотреть **Настройки → Статус сети → Ethernet**. В роли HUD имя AP начинается с `G5500-HUD-`.
3. Откройте `http://<адрес Ethernet>`. Для внешних программ используйте этот же адрес и [обычные порты](../setup/network.md#порты). Специальный Ethernet-протокол не нужен.

Ethernet имеет приоритет маршрута перед Wi-Fi STA. При потере кабеля сохраняется доступ через настроенный Wi-Fi и AP по [обычным правилам](../setup/network.md#резервная-точка-доступа). Соединение с кабелем без DHCP ещё не даёт IP. «Ошибка запуска» означает отказ инициализации PHY: проверьте профиль платы и питание. Для постоянного адреса создайте привязку DHCP в роутере. Прямому соединению с компьютером нужен DHCP-сервер в этой сети.

Текущий проводной адрес отмечен `ETH:`. В `GET /api/network` доступны `ethernetSupported`, `ethStarted`, `ethLink`, `ethConnected`, `ethIp`; `connected` по-прежнему относится к Wi-Fi STA. В `/api/status` поле `ip` выбирает Ethernet, затем STA, затем AP; `rssi` относится только к Wi-Fi. `ethLink` показывает кабель, `ethConnected` — готовый IPv4. Эти сведения доступны и через [UART API](../api/command-api.md).

## Начальная распиновка

| Назначение | GPIO |
|---|---|
| Датчики положения AZ / EL | 36 / 35, только вход, ADC1 |
| AZ LEFT / RIGHT | 32 / 33 |
| EL DOWN / UP | 14 / 15 |
| Скорость / ENABLE AZ / EL | 4 / 2 |
| UART0 RX / TX | 3 / 1 |
| HC-05 RX / TX / STATE | 39 / 17 / 5 |

GPIO0, 16, 18, 19, 21, 22, 23, 25, 26, 27 заняты Ethernet и заблокированы для переназначения, включая имитацию. LAN8720: адрес 1, питание GPIO16, MDC23, MDIO18, внешний clock на GPIO0; параметры совпадают с [профилем Espressif](https://github.com/espressif/arduino-esp32/blob/3.3.11/variants/wt32-eth01/pins_arduino.h).

Кнопка подтверждения по умолчанию отключена: BOOT/GPIO0 занят PHY. Используйте веб-кнопку либо назначьте свободный GPIO. GPIO12 оставляйте LOW при сбросе; GPIO2 не должен быть подтянут внешней схемой к HIGH при входе в загрузчик. GPIO35/36/39 не имеют внутренних подтяжек. Названия CFG и 485_EN относятся к заводской прошивке; здесь это GPIO32 и GPIO33.

Для датчиков используйте [делители и защиту ADC ESP32](../hardware/adc-input.md), для двигателя — [выбранный силовой интерфейс](../hardware/index.md) с распиновкой из таблицы выше. После монтажа выполните [первый запуск](../quickstart.md), проверку направлений и калибровку.

Bluetooth по умолчанию выключен; при включении автоматический транспорт — встроенный SPP. Для HC-05 проверьте свободные выводы и их уровни по [настройкам оборудования](../setup/configuration.md).

## Вариант без веба и с OTA

`wt32_eth01` использует раздел приложения 3 МиБ без OTA. Для обновления по сети на плате с 4 МиБ предусмотрен **`wt32_eth01_noweb`**: без HTTP/WebSocket, дисплея и Bluetooth, с [командным API](../api/command-api.md) и ArduinoOTA через Ethernet или Wi-Fi. Первую запись и смену разметки выполняйте через UART.

```sh
pio run -e wt32_eth01_noweb
```

[Настройка ArduinoOTA без браузера](../maintenance/ota.md#arduinoota-без-браузера), [диагностика](../maintenance/diagnostics.md).
