# ESP32-C3 без дисплея

[Документация](../index.md)

Профиль `esp32c3_4mb` предназначен для ESP32-C3 с Flash **4 МиБ**, без дисплея и PSRAM. Управление и настройка доступны через веб и внешние API. По умолчанию выбрана роль **Контроллер**, имитация выключена, выходы привода и обратная связь не назначены. Можно выбрать роль HUD.

Для платы со встроенным круглым экраном используйте отдельный профиль [ESP32-2424S012C-Y(B)](esp32-2424s012c.md).

## Сборка и загрузка

```sh
pio run -e esp32c3_4mb
```

Библиотеки дисплея не нужны. Arduino CLI:

```sh
./tools/build_arduino.sh esp32-c3
```

В Arduino IDE выберите **ESP32C3 Dev Module**, Flash 4 MB, Flash Mode DIO, **USB CDC On Boot: Enabled**, Partition Scheme **Huge APP (3MB No OTA/1MB SPIFFS)**. В `build_config.hpp` задайте `BOARD_ESP32_C3` и `DISPLAY_NONE`; `BOARD_AUTO` также выбирает этот профиль для C3.

Подключите плату к компьютеру и укажите её порт:

```sh
pio run -e esp32c3_4mb -t upload --upload-port /dev/ttyACM0
```

Замените порт на фактический: на плате с USB-UART мостом это может быть `/dev/ttyUSB0`. Профиль включает native USB Serial/JTAG на GPIO18/19; его доступность через разъём зависит от разводки платы. Если нужен режим загрузки, удерживайте BOOT, нажмите RESET и отпустите BOOT.

Разметка содержит один раздел приложения 3 МиБ: **OTA недоступно**, обновляйте через USB/UART.

## Первый запуск и GPIO

1. Подключитесь к точке доступа `G5500-Rotator-XXXXXX` и откройте `http://192.168.4.1/`.
2. Пройдите [первую настройку](../setup/first-start.md), выбрав поворотку и интерфейс привода.
3. На шаге оборудования назначьте GPIO подключённого привода, датчиков и местных органов управления. Подтвердите оборудование и завершите мастер.

| Линии | Использование в профиле |
|---|---|
| GPIO0–10 | Доступны для назначения с учётом уже выбранных функций и разводки платы |
| GPIO0–4 | Также доступны для аналоговой обратной связи ADC1 |
| GPIO9 / BOOT | Кнопка подтверждения цели по умолчанию; значение −1 в оборудовании освобождает её |
| GPIO20 / GPIO21 | UART0 RX / TX по умолчанию; для другого назначения отключите оба UART-пина значением −1 |
| GPIO11–17 | Недоступны для назначения в профиле |
| GPIO18 / GPIO19 | Зарезервированы под native USB |

Назначайте только выведенные на вашей плате контакты, свободные от встроенных компонентов. GPIO2, GPIO8 и GPIO9 участвуют в выборе режима загрузки: подключённая цепь должна сохранять нужные уровни при включении. Аналоговые входы и UART используют уровни 3,3 В. Назначение GPIO5 как ADC не поддерживается. Ограничения выводов описаны в [документации Espressif](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c3/api-reference/peripherals/gpio.html).

Для двух релейных направлений AZ можно назначить GPIO6 и GPIO7, выбрать режим привода **Штатный блок Yaesu**, оставить ADC и скорость AZ равными −1 и не назначать EL. Мастер пропустит калибровку и регуляторы; движение выполняется удержанием стрелок. Для позиционирования назначьте обратную связь и выполните калибровку. Подключайте GPIO к совместимым входам драйвера реле, а не к катушкам.

Датчики MT6701/AS5600 подключаются к выбранным свободным SDA/SCL. У C3 [один I²C-контроллер](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c3/api-reference/peripherals/i2c.html), поэтому два датчика должны использовать одну пару SDA/SCL и разные адреса. Встроенного Bluetooth SPP нет; внешний HC-05 настраивается через свободные UART-пины.
