# Classic ESP32: Wi-Fi, веб и встроенный SPP

[Главная](../../README.md)

Эта конфигурация рассчитана на классический ESP32 WROOM/WROVER с Flash 4 МБ,
без требования PSRAM. Используются Wi-Fi, компактный HTTP-интерфейс,
Bluetooth Classic SPP, GS-232 по USB/UART, rotctld / Hamlib, N1MM и PstRotator. Привод управляется прямым PWM;
PID, автотюн, рампа и удержание позиции отсутствуют. Сохраняются ограничения
диапазона, защита обратной связи, остановка при отсутствии движения,
блокировка реверса и тайм-аут ручного удержания.

Основной профиль `esp32_spp` исключает HUD, WebSocket, MQTT, OTA,
дисплей и локальный джойстик.
`esp32_spp_hud` добавляет связь с удалённым пультом по UDP 4534.

## Сборка

Установите pioarduino/PlatformIO и Python3. Скрипт создаёт отдельные каталоги
проекта и SDK, собирает библиотеки Arduino и приложение. При первом запуске
нужен доступ к интернету для загрузки зависимостей.

```sh
python3 tools/build_esp32_spp.py --pio pio
```

Если команда PlatformIO называется иначе, укажите её через `--pio`.
Для сборки с HUD:

```sh
python3 tools/build_esp32_spp.py --pio pio --hud
```

Готовые файлы находятся в `build/esp32-spp-firmware/`. Скрипт выполняет только
сборку. Файл `manifest.json` содержит хеши образов и конфигурации SDK.

SDK оставляет Classic SPP, выключает BLE/Mesh/A2DP/HFP, использует стеки
BTC 4096 / BTU 4352 и один контроллерный ACL-канал. Внутренних слотов Bluedroid
оставлено два: второй необходим для восстановления слушателя после отключения
SPP-клиента. Одна плата принимает одного SPP-клиента. Конфигурация SDK хранится
в `tools/sdkconfig_esp32_spp.defaults`.

## Запись и подключение

Профиль предназначен для обновления настроенного контроллера с сохранением
NVS. Первичную настройку оборудования и мастер первого запуска выполните
полной прошивкой, затем установите этот профиль без очистки Flash.
Компактные страницы позволяют менять настройки и калибровки действующего
контроллера; полного мастера первого запуска в них нет.

Используйте [порядок USB-прошивки](../build.md#первая-прошивка-через-usb)
и файлы из `build/esp32-spp-firmware/`. При совместимой разметке достаточно
записать `firmware.bin` по адресу `0x10000`, сохранив настройки и калибровки.
До обновления остановите привод и закройте Serial Monitor.

Распиновка и ограничения GPIO описаны в [инструкции классического ESP32](classic-esp32.md#подключение).
После загрузки откройте адрес платы в браузере. В разделе «Оборудование и сеть»
выберите привод, GPIO, Wi-Fi и транспорт Bluetooth «Встроенный SPP».
Имя Bluetooth — **G5500-Rotator**. USB GS-232/H4 работает на 9600 бод;
расширенный командный USB API в этом профиле выключен.

## Настройка и управление

- **Управление** (`/`): положение, цель, ручное удержание, STOP, рабочий PWM
  и сброс ошибок движения. Ручной и автоматический режимы сохраняют свою логику.
- **Калибровка** (`/calibration`): выберите диапазоны и метод. Установите привод
  на указанный механический угол, остановите его и нажмите «Запомнить».
  Произвольные диапазоны поддерживают дополнительные точки и оба направления
  изменения показаний датчика. Сброс точек требует повторной калибровки.
- **Настройки** (`/settings`): модель, имя, порты N1MM / PstRotator, автоследование протоколов, сохранённые скорости,
  лимиты PWM, допуск остановки, защитные тайм-ауты и частота управления.
  Сохранённая скорость и рабочее значение на главной странице могут отличаться.
- **Оборудование и сеть** (`/hardware`): подключение, транспорт Bluetooth,
  интерфейс привода и GPIO. **Датчики** (`/adc`): показания обратной связи.

Ошибка движения блокирует новые команды до устранения причины и сброса.
При сохранении или запоминании калибровки дождитесь подтверждения. Если связь
прервалась, обновите данные и проверьте фактический результат перед повтором.

## Подключение программ

| Протокол | Подключение по умолчанию |
| --- | --- |
| rotctld / Hamlib и GS-232 | IP контроллера, TCP 4533 |
| N1MM Rotor | IP контроллера, UDP 12040 |
| N1MM: отчёт положения | UDP 13010, адрес отправителя команды или заданный IPv4 |
| PstRotator | IP контроллера, UDP 1234; ответ на UDP 1235 |
| GS-232 | Bluetooth SPP или USB/UART, строки с CR |

UDP-порты и IPv4 получателя отчётов задаются в «Настройки → Протоколы управления».
Имя ротатора для N1MM должно совпадать с названием контроллера.
Для каждого протокола отдельно выбирается автоследование в ручном режиме:
при включении числовая цель выполняется сразу, при выключении ожидает
подтверждения на главной странице. Направления и STOP выполняются сразу.
В автоматическом режиме цели выполняются без дополнительного подтверждения.
Обновление прошивки сохраняет ранее выбранные порты и политики протоколов.

## Диагностика

При одновременной работе HTTP и SPP возможны сбросы HTTP-соединений.
Для изменения настроек при повторяющихся сбоях отключите SPP-клиента,
обновите страницу и проверьте сохранённые значения. Команда USB `H4` показывает
свободный heap, минимум, ошибки выделения памяти и ошибки передачи HTTP.
Отключение PID не означает отключения защит датчиков и тайм-аута движения.
