# Первый запуск

[Документация](index.md)

## Подготовка

1. Выберите [плату, Flash и дисплей](configuration.md#выбор-конфигурации). Для проверки без механики можно включить имитацию на любой плате.
2. Выберите [подключение привода](hardware.md). Монтируйте при выключенном питании; до проверки выходов оставьте силовое питание двигателей отключённым.
3. [Соберите и запишите прошивку через USB](build.md). Профиль должен соответствовать физической плате. Для переделанной CrowPanel используйте только `crowpanel_21_az`.

## Первое подключение

1. Подключитесь к `G5500-Rotator-XXXXXX`. На новом устройстве сеть без пароля; ранее сохранённый пароль остаётся действующим.
2. Откройте `http://192.168.4.1`. Если устройство уже настроено, используйте адрес на дисплее или [найдите его через диагностику](diagnostics.md#нет-доступа).
3. В **Настройки → Сеть и подключение** задайте пароль AP и при необходимости сеть роутера. Смена пароля AP перезапускает устройство; подключение к роутеру применяется без перезапуска. [Подробнее о Wi-Fi](network.md).
4. В **Пульт и связь** выберите роль. Для контроллера продолжайте ниже; для удалённого пульта перейдите к [настройке HUD](hud.md).
5. Откройте `/hardware`, выберите интерфейс, физический привод или имитацию и проверьте GPIO. После изменения сохраните настройки, дождитесь перезапуска и [подтвердите пробный запуск](configuration.md#применение-и-восстановление-доступа).

Профиль `esp32_4mb_noweb` не имеет веб-страницы: настройте оборудование и сеть через [командный API](command-api.md#оборудование-и-восстановление).

## Первое движение

1. Выберите модель G-5500 для двух осей или G-800DXA для одной AZ. В физическом режиме полностью отключённые GPIO EL также выбирают одноосевую модель.
2. Выполните проверки питания и сигналов из инструкции своего привода. Затем включите силовое питание и коротко проверьте направления и STOP в ручном режиме. До калибровки используйте простой регулятор и ориентируйтесь на реальное положение.
3. Настройте [диапазоны и калибровку](az-range.md) каждой оси. В имитации калибровка датчиков не нужна.
4. Для регулируемого привода выполните [настройку регуляторов](regulator-tuning.md); для G-5500 через Yaesu скорость фиксированная.
5. Проверьте небольшое числовое наведение в обе стороны, затем настройте [внешнюю программу](integrations.md).

Далее: [повседневное управление](usage.md). Если движение недоступно — [диагностика](diagnostics.md).
