# Первый запуск

[Документация](index.md)

## Подготовка

1. Выберите [плату, Flash и дисплей](setup/configuration.md#выбор-конфигурации). Для проверки без механики можно включить имитацию на любой плате.
2. Выберите [подключение привода](hardware/index.md). Монтируйте при выключенном питании; до проверки выходов оставьте силовое питание двигателей отключённым.
3. Установите [pioarduino / PlatformIO](#установка-pioarduino--platformio) либо используйте [Arduino IDE](build.md#arduino-ide-2x), затем [соберите и запишите прошивку через USB](build.md). Профиль должен соответствовать физической плате. Для переделанной CrowPanel используйте только `crowpanel_21_az`.

## Установка pioarduino / PlatformIO

1. Установите [Visual Studio Code](https://code.visualstudio.com/) и [Git](https://git-scm.com/downloads). В Linux также нужен пакет `python3-venv`.
2. В VS Code откройте **Extensions** (`Ctrl+Shift+X`), установите одно расширение: [pioarduino IDE](https://marketplace.visualstudio.com/items?itemName=pioarduino.pioarduino-ide) или [PlatformIO IDE](https://marketplace.visualstudio.com/items?itemName=platformio.platformio-ide). Дождитесь установки компонентов и перезапустите VS Code. Команда `pio` входит в комплект расширения.
3. Через **File → Open Folder** откройте корень этого проекта, где находится `platformio.ini`. Нужная версия платформы ESP32 от pioarduino уже задана в нём и загрузится при первой сборке.
4. Откройте терминал расширения кнопкой **PlatformIO: New Terminal** на нижней панели VS Code и проверьте `pio --version`. Из этого терминала можно сразу выполнять [команды сборки](build.md#platformio).

Без VS Code можно установить [PlatformIO Core по официальной инструкции](https://docs.platformio.org/en/latest/core/installation/methods/installer-script.html).

### Команда pio в терминале Windows

Чтобы `pio` работала в обычном PowerShell или cmd после установки расширения:

1. В меню «Пуск» найдите **Изменение переменных среды текущего пользователя**. В пользовательских переменных выберите **Path → Изменить → Создать** и добавьте отдельной строкой:

   ```text
   %USERPROFILE%\.platformio\penv\Scripts
   ```

2. Сохраните изменения. Полностью закройте и заново откройте терминал; для встроенного терминала перезапустите весь VS Code.
3. Проверьте доступность команды:

   ```powershell
   pio --version
   where.exe pio
   ```

Если команда не найдена, проверьте наличие `pio.exe` в указанной папке и завершение установки расширения. При нестандартном расположении PlatformIO добавьте в `Path` фактическую папку с `pio.exe`. [Настройка терминала для Windows, Linux и macOS](https://docs.platformio.org/en/latest/core/installation/shell-commands.html).

## Первое подключение

1. Подключитесь к `G5500-Rotator-XXXXXX`. На новом устройстве сеть без пароля; ранее сохранённый пароль остаётся действующим.
2. Откройте `http://192.168.4.1`. Если устройство уже настроено, используйте адрес на дисплее или [найдите его через диагностику](maintenance/diagnostics.md#нет-доступа).
3. На новом устройстве откроется [мастер настройки](setup/first-start.md). Выберите сеть, дождитесь подключения и укажите роль контроллера или HUD. После необходимого перезапуска мастер продолжится с сохранённого шага.
4. Следуйте выбранной ветке: оборудование и GPIO, проверка входов, калибровка контроллера либо добавление повороток на HUD, затем внешние программы и проверка управления.
5. Для повторного прохода откройте **Мастер настройки** в верхнем меню или `/setup`. Кнопка **Сохранить и выйти** сохраняет шаг и открывает управление. Незавершённый мастер не блокирует движение.

Профили `esp32_4mb_noweb` и `wt32_eth01_noweb` не имеют веб-страницы: настройте оборудование и сеть через [командный API](api/command-api.md#оборудование-и-восстановление).

## Первое движение

1. Выберите модель G-5500 для двух осей или G-800DXA для одной AZ. В физическом режиме полностью отключённые GPIO EL также выбирают одноосевую модель.
2. Выполните проверки питания и сигналов из инструкции своего привода. Затем включите силовое питание и коротко проверьте направления и STOP в ручном режиме. До калибровки используйте простой регулятор и ориентируйтесь на реальное положение.
3. Настройте [диапазоны и калибровку](setup/az-range.md) каждой оси. В имитации калибровка датчиков не нужна.
4. Для регулируемого привода выполните [настройку регуляторов](setup/regulator-tuning.md); для G-5500 через Yaesu скорость фиксированная.
5. Проверьте небольшое числовое наведение в обе стороны, затем настройте [внешнюю программу](integrations/index.md).

Далее: [повседневное управление](control/index.md). Если движение недоступно — [диагностика](maintenance/diagnostics.md).
