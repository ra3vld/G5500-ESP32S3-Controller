Для **CrowPanel 2.1 с локальным AZ** используйте [отдельную инструкцию переделки и подключения Yaesu / BTS7960](../boards/crowpanel-az.md). Она задаёт другие GPIO, уровни RX/TX и обязательную инверсию BOOT. Распиновка DevKit и обычный профиль `crowpanel_21` для такого подключения не подходят.

Таблицы и схемы показывают распиновку по умолчанию. Текущие назначения проверяйте в разделе [«Распиновка GPIO»](../setup/configuration.md#распиновка-gpio) и ответе `/api/hardware`.

Для аналоговой обратной связи используйте [делитель ADC под свой микроконтроллер](adc-input.md#номиналы-под-конкретный-контроллер). Напрямую подавать 5 В на GPIO нельзя; после изменения делителя повторите калибровку.

Для Yaesu приведён [пример изоляции обратной связи 0–5 В на HCNR201](yaesu-feedback-isolation.md): питание +5,5 В с каждой стороны, раздельные земли и настройка передачи 5 В → 5 В. Перед подключением настройте передачу сигнала и согласуйте выход с АЦП.

## G-800DXA: интерфейс YAESU

Подключайтесь к штатному блоку через mini-DIN **EXT CONTROL**. Активный HIGH GPIO включает согласующий выход, который замыкает вход направления Yaesu на общий контакт. Мотор питается штатным блоком.

[Полная инструкция G-800DXA](g800dxa/index.md) содержит распайку, схемы, детали, проверку, настройку и калибровку:

- [А: общая земля, 74HCT245 и MCP6002](g800dxa/index.md#вариант-а-общая-земля-74hct245-и-mcp6002).
- [Б: ADuM1201 и TLV9001 с питанием от VD pin 6](g800dxa/index.md#вариант-б-adum1201-tlv9001-и-pin-6).
- [В: 6N137 и отдельное изолированное питание](g800dxa/index.md#вариант-в-6n137-и-изолированное-питание).

## Два независимых BTS7960 / IBT-2

[Единое руководство BTS7960](bts7960/index.md) описывает прямое подключение с логикой 3,3 В, буфер 74HCT245 с логикой 5 В и изолированное управление через шесть PC817C. В нём приведены схемы, GPIO, питание, датчики и порядок проверки. GPIO скорости в этом интерфейсе служат ENABLE; PWM передаётся по RPWM/LPWM.

## Распиновка ESP32-S3 и прежней S2

| Сигнал | GPIO |
|---|---|
| AZ feedback | 4 |
| EL feedback, только G-5500 | 5 |
| LEFT / CCW | 15 |
| RIGHT / CW | 16 |
| UP / DOWN, только G-5500 | 17 / 18 |
| PWM скорости, опционально | 21 |
| Пользовательская кнопка, по умолчанию | 0 |
| TFT MOSI / SCK / MISO | 10 / 11 / 2 |
| TFT CS / DC / RST | 12 / 13 / 14 |
| XPT2046 CS / IRQ | 8 / 9 |
| HC-05 RX / TX / STATE | 6 / 7 / 3 |
| UART0 RX / TX | 44 / 43 |

Эта таблица относится к S3 и прежней S2 в интерфейсе YAESU. Выбранный дисплей может быть NONE, ILI9341/XPT2046 или параллельный LCD1602. Схема с TFT на основе оригинала UA1CFM: [PDF](g5500/g5500-esp32s3-tft-schematic.pdf), [SVG](g5500/g5500-esp32s3-tft-schematic.svg), [PNG](g5500/g5500-esp32s3-tft-schematic.png). У входов EL/AZ добавлены нижние BAT85 D7/D8 и общий R35 500 Ом между 3,3 В и GND; при сборке используйте [номиналы ADC](adc-input.md).

## Классический ESP32 WROOM/WROVER

Для ESP32 WROOM/WROVER используйте [отдельную таблицу GPIO](../boards/classic-esp32.md). Схемы S3 выше показывают другие GPIO и требуют переноса по назначению сигнала. При встроенном SPP внешний модуль не нужен. Для HC-05 выберите `BT_HC05` и подключите его по таблице ESP32: RX39/TX5/STATE15. Обратная связь AZ/EL идёт на GPIO34/35 через существующие согласующие цепи; направления и PWM/ENABLE используют GPIO25/26/14/27/32/33.

## Входы кнопок и джойстика

На странице `/hardware` выберите режим входов, назначьте их GPIO и при необходимости инверсию AZ/EL. Сохраните и подтвердите пробный запуск. Для джойстика после подтверждения GPIO доступно измерение центра и крайних положений. Порядок подключения и калибровки описан в [инструкции кнопок и джойстика](../control/local-controls.md). Эти входы работают также в роли HUD.
