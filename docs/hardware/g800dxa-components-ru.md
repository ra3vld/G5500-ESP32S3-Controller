# Компоненты для подключения G-800DXA

Выберите [схему с общей землёй](g800dxa-connection.md) или [изолированный канал скорости](g800dxa-speed-isolated.md). Обозначения элементов ниже соответствуют этим схемам. При покупке сверяйте производителя, корпус и распиновку; электрически похожие детали могут иметь другие выводы.

## Основные компоненты

| Позиция | Компонент | Исполнение и применение |
|---|---|---|
| U9 | MCP6002T-I/SN | SOIC-8, буфер аналогового выхода в обеих схемах; MCP6002-I/P в DIP8 имеет те же номера выводов |
| Q1 | BC547B, Diotec | TO-92, C1/B2/E3; драйвер LED изолированного канала, база через 2,2 кОм |
| U8, изолированная схема | 6N137-L, Lite-On | DIP8, быстрая оптопара для PWM 20 кГц |
| U10 | 74HC14N | DIP14, восстановление полярности после 6N137 |
| U11 | AM1SS-0509SJZ, Aimtec | SIP4, изолированный DC/DC 5 → 9 В, 1 Вт; используется вместе с U12 и нагрузкой R34 |
| U12 | L78L05ACZ, ST | TO-92, стабилизатор 5 В; распиновка должна соответствовать ST |
| U8, общая земля | 74HCT245N | DIP20, согласование PWM 3,3 → 5 В; HC не подходит как прямая замена |
| U3/U4 | PC817C | DIP4, управление направлениями CW/CCW; используйте группу CTR C |
| D2 | BAT85 | Ограничение входа ADC по схеме |

В варианте с LCD1602 можно использовать свободный канал A7/B7 уже установленного 74HCT245 при тех же питании, DIR и /OE. Не заземляйте входы, занятые дисплеем.

## Пассивные элементы

Нужны обычные резисторы 1% на 330 Ом, 470 Ом, 1 кОм, 2,2 кОм, 4,7 кОм, 5,1 кОм, 6,8 кОм, 10 кОм, 100 кОм и 100 Ом. Для большинства достаточно 0,125–0,25 Вт. **R34: 820 Ом, 0,5 Вт**. В универсальном делителе AZ для S2/S3: **R3 6,8 кОм от сигнала, R11 4,7 кОм на землю, оба 1%**; [расчёт](adc-input.md). Конденсаторы 100 нФ и 1 мкФ для сигнала, 0,33 мкФ для входа стабилизатора, по 4,7 мкФ для DC/DC. Выходной конденсатор DC/DC — не менее 25 В. Для керамики проверить эффективную ёмкость под рабочим напряжением. Выбирайте мощность, допуск и рабочее напряжение по указанным значениям.

**При подборе под S3:** R3 = 4,7 кОм, R11 = 5,1 кОм, оба 1%, для входного сигнала не выше 5,5 В. Для S2 и общего варианта остаются R3 = 6,8 кОм, R11 = 4,7 кОм. [Таблица вариантов](adc-input.md#номиналы-под-конкретный-контроллер).

**S1:** переключатель SPDT ON-ON без среднего положения OFF, с разрывом перед замыканием. **VR1:** линейный потенциометр 10 кОм между EXT CONTROL pin 6 (+5 В, после проверки) и pin 5, движок на ручной вход S1. Номинал VR1 выбран для схемы, диапазон проверить под нагрузкой. В упрощённом варианте без VR1 ручной вход S1 соединяется с pin 6.

## Замены и монтаж

- MCP6001 не является заменой MCP6002 по выводам. У неиспользуемого канала B MCP6002 подключите IN+ к земле своего домена, IN− к OUT.
- AO3400A нельзя ставить вместо BC547B без изменения схемы входа и назначения выводов.
- После 6N137 сигнал имеет уровни 0/5 В, поэтому подходит 74HC14. Для непосредственного сигнала ESP32 3,3 В при питании буфера 5 В используйте HCT.
- Нерегулируемый B0505S 5 → 5 В не заменяет узел AM1SS + L78L05. B0509S-1WR3 допускается только после сверки распиновки, минимальной нагрузки и конденсаторов по его документации.
- Перед подключением pin 3 измерьте питание, выходной диапазон 0–5 В и уровни под нагрузкой. Уточнение pin 6 и подключение VR1 приведены в [инструкции переключения скорости](g800dxa-connection.md#переключение-шим--ручная-скорость).
