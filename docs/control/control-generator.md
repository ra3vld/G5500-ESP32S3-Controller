# Генератор команд управления

[Документация](../index.md) · [Управление](index.md)

Скрипт `tools/control_generator.py` генерирует команды наведения и отправляет их по выбранному протоколу. Нужен Python 3. На Linux/macOS последовательный порт работает без дополнительных пакетов; на Windows установите `python -m pip install pyserial`. Закройте другие программы, использующие тот же COM-порт.

## Меню

Запустите из корня проекта:

```sh
python3 tools/control_generator.py
```

Выбирайте пункты меню по номерам: введите цифру рядом с нужным вариантом и нажмите Enter. Выберите протокол, оси AZ / EL / AZ+EL, одиночную цель или непрерывный проход, затем предпросмотр или отправку. Укажите подключение и координаты в градусах. В непрерывном режиме для каждой оси задаются собственные минимум, максимум и шаг, а пауза между командами общая. Подсказки показывают значения по умолчанию; Enter принимает их. Диапазон меню по умолчанию — AZ 0…360°, EL 0…180°: замените его своим допустимым диапазоном.

Предпросмотр выводит команды без подключения и ожидания. По умолчанию показаны 20 команд. Отправка непрерывной последовательности работает до Ctrl+C; можно задать число команд. В меню отправки число `0` означает отсутствие ограничения.

## Протоколы и подключение

| Значение `--protocol` | Протокол | Подключение | Порт по умолчанию |
|---|---|---|---|
| `gs232` | GS-232 | TCP или USB/UART | TCP 4533 |
| `rotctld` | rotctld / Hamlib | TCP или USB/UART | TCP 4533 |
| `n1mm` | N1MM | UDP; только AZ | 12040 |
| `pst` | PstRotator | UDP | 1234 |
| `http` | HTTP API | HTTP | 80 |
| `api` | Командный API | TCP, UDP или USB/UART | TCP 4533, UDP 4535 |

`--host` задаёт IP или имя устройства без схемы и порта (по умолчанию `192.168.4.1`); `--port` переопределяет порт. Для сети командного API выберите `--transport tcp` или `--transport udp`. `--serial PORT` выбирает последовательное подключение, `--baud` — скорость (по умолчанию 9600). `--timeout` задаёт время ожидания ответа в секундах (по умолчанию 2). Используйте [скорость и порт своего устройства](../api/command-api.md#подключение); UART, занятый HUD, недоступен для этих команд.

Для N1MM задайте `--rotor-name` с именем поворотки из настроек контроллера (по умолчанию `G5500`). Имена с XML-символами `<`, `>`, `&`, запятыми и переводами строк не принимаются.

## Запуск с параметрами

Без `--send` скрипт показывает предпросмотр. `--dry-run` явно выбирает этот же режим. `--interactive` открывает меню и при наличии аргументов.

Предпросмотр прохода AZ от −20° до 190° с шагом 15°:

```sh
python3 tools/control_generator.py --protocol gs232 --axes az --mode sweep --az-min -20 --az-max 190 --az-step 15 --interval 2 --count 20
```

Непрерывная отправка PstRotator UDP с независимыми диапазонами AZ и EL, пауза 1,5 секунды:

```sh
python3 tools/control_generator.py --protocol pst --host 192.168.4.1 --send --axes both --az-min 0 --az-max 180 --az-step 10 --el-min 0 --el-max 90 --el-step 5 --interval 1.5
```

Одиночная цель через USB/UART:

```sh
python3 tools/control_generator.py --protocol gs232 --serial COM3 --send --mode single --axes both --az 120 --el 30
```

На Linux замените `COM3`, например, на `/dev/ttyUSB0`. Для native USB используйте фактический порт устройства, например `/dev/ttyACM0`.

Одиночная цель EL по HTTP:

```sh
python3 tools/control_generator.py --protocol http --host 192.168.4.1 --send --mode single --axes el --el 25
```

Десять команд через командный API UDP с последующим STOP:

```sh
python3 tools/control_generator.py --protocol api --transport udp --host 192.168.4.1 --send --az-min 0 --az-max 90 --az-step 10 --interval 2 --count 10
```

Предпросмотр одиночной команды N1MM:

```sh
python3 tools/control_generator.py --protocol n1mm --rotor-name G5500 --mode single --az 135
```

Все параметры: `python3 tools/control_generator.py --help`.

## Проход, подтверждение и остановка

Непрерывный режим `--mode sweep` начинает с минимума, доходит до максимума и возвращается обратно. Граничная координата не дублируется при развороте. Если диапазон не делится на шаг, последний шаг сокращается. Например, 0…10° с шагом 4° даёт `0, 4, 8, 10, 6, 2, 0, …`. Если шаг больше диапазона, чередуются обе границы. Равные минимум и максимум дают постоянную цель.

При AZ+EL обе координаты передаются одной командой, каждая ось разворачивается у своих границ независимо. Пауза начинается после завершения отправки и чтения предусмотренного протоколом ответа; достижения цели скрипт не ожидает. Подтверждение и запрос положения добавляют время к интервалу между командами. Выбирайте паузу с учётом нужного характера движения: новая цель может поступить до достижения предыдущей.

`--count N` ограничивает число целевых команд; запросы положения, служебные запросы API и STOP в него не входят. В непрерывной отправке без `--count` ограничений нет. После последней целевой команды выдерживается заданная пауза, затем отправляется STOP. В режиме `--mode single` передаётся одна цель, а после успеха скрипт завершается, позволяя контроллеру закончить наведение.

rotctld передаёт обе координаты, GS-232 для управления EL использует команду AZ+EL. Если выбрана одна ось и протокол требует вторую, скрипт перед каждой целью читает её текущее положение и подставляет его в команду. Это задаёт второй оси текущую координату, в том числе если она ещё движется; прежняя цель этой оси не сохраняется. GS-232 сообщает положение с точностью до целого градуса. В предпросмотре вместо чтения требуется `--hold-az` или `--hold-el`, например:

```sh
python3 tools/control_generator.py --protocol rotctld --mode single --axes az --az 120 --hold-el 30
python3 tools/control_generator.py --protocol gs232 --mode single --axes el --el 25 --hold-az 90
```

N1MM управляет только AZ. Для G-800DXA выбирайте AZ; наличие EL и допустимые координаты зависят от модели, диапазонов и калибровки контроллера.

Внешние цели GS-232, rotctld, N1MM и PstRotator в ручном режиме могут [ожидать подтверждения](index.md#режимы). Для непрерывного наведения заранее выберите автоматический режим либо включите автоследование нужного протокола. Скрипт не изменяет режим, настройки, калибровки и диапазоны. HTTP и командный API используют явные локальные цели, выполняемые сразу.

Для внешних протоколов интерпретация AZ зависит от настройки [«Угол AZ от программ»](../setup/az-range.md#непрерывные-углы-и-направления). Для проверки точного механического прохода выберите на контроллере механический угол; HTTP и командный API задают механические координаты. PstRotator передаёт `LP=0` вместе с AZ, чтобы прежняя команда другой программы не добавляла 180°. Ограничения контроллера и приоритет активной предустановки продолжают действовать.

N1MM/PstRotator UDP не подтверждают принятие целевой команды: вывод строки означает отправку пакета. GS-232 после цели запрашивает положение, чтобы прочитать возможный отказ `?>`; этот ответ не подтверждает достижение цели или фактическое движение. Командный API в предпросмотре показывает путь и поля запроса; идентификаторы сессии и служебные пакеты создаются только при подключении.

При Ctrl+C или ошибке после попытки отправить цель скрипт пытается отправить общий STOP выбранным протоколом и закрывает соединение. STOP относится к обеим осям. При потере связи доставка STOP не гарантирована; сообщение об ошибке остановки выводится отдельно. Для UDP успешная отправка STOP также не подтверждает его приём. Ошибка возвращает код 1 (ошибка синтаксиса аргументов — 2), Ctrl+C — 130, успешное завершение — 0.
