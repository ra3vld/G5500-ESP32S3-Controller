# Запись и воспроизведение экрана CrowPanel

[Документация](../index.md) · [CrowPanel: экран и управление](../boards/crowpanel-21.md)

CrowPanel может передавать по нативному USB состояние экрана, события сенсора
и энкодера и состояние осей. Компьютер сохраняет поток в журнал JSONL.
Проигрыватель восстанавливает экран тем же кодом LVGL, который используется
в прошивке, и позволяет сохранить видео MP4 размером 480×480 или 600×600
с отображением действий пользователя.

## Сборка прошивки

Поток включается флагом `CROWPANEL_USB_TRACE=1`. В обычных сборках флаг равен
нулю. Для стандартной CrowPanel предусмотрен отдельный профиль:

```sh
pio run -e crowpanel_21_trace
```

Запишите выбранную сборку по [инструкции USB-прошивки](../build.md#первая-прошивка-через-usb).
В этом профиле нативный USB выделен под телеметрию: командный API и обычный
диагностический вывод через него отключены. Управление через веб, сеть и
внешний UART сохраняется. Диагностический журнал доступен через веб.

## Запись

Для рекордера нужны Linux или macOS и Python 3.10 или новее; дополнительные Python-пакеты
не требуются. Закройте монитор порта и другие приложения, использующие
тот же USB-порт. На Linux найдите устойчивое имя подключённой CrowPanel:

```sh
ls -l /dev/serial/by-id/
```

Запустите запись, подставив имя её порта:

```sh
python3 tools/crowpanel_trace.py record \
  --port /dev/serial/by-id/ИМЯ_CROWPANEL \
  --output session.jsonl
```

Управляйте настоящим пультом. Для окончания нажмите Ctrl+C. Для записи
ограниченной длительности добавьте `--duration 60` — время задаётся в секундах.
Рекордер читает поток и не отправляет команд управления устройству.
Он не переключает линии DTR/RTS. На macOS вместо пути из `/dev/serial/by-id/`
укажите порт CrowPanel вида `/dev/cu.usbmodem…`. Для каждой записи используйте
новое имя файла: существующий журнал не перезаписывается.

Проверьте содержимое и статистику журнала:

```sh
python3 tools/crowpanel_trace.py inspect session.jsonl
```

## Просмотр

Для визуализатора нужны Python 3.10 или новее, компилятор C++17, CMake и исходники LVGL
9.6.0. После сборки профиля CrowPanel LVGL находится в каталоге библиотек
PlatformIO. Для сохранения MP4 дополнительно установите FFmpeg с кодировщиком
`libx264`.

```sh
python3 tools/crowpanel_trace_viewer.py view session.jsonl
```

Откройте напечатанный локальный адрес в браузере. Плеер поддерживает паузу,
перемотку и выбор скорости. Кнопка **«Сохранить MP4»** создаёт видео всей
записи с частотой 30 кадров/с и предлагает скачать его. Экран отрисовывается
нативным LVGL; браузер показывает полученные кадры и органы управления плеером.

Включите **«Тапы, свайпы и энкодер»**, чтобы видеть действия из журнала:

- Тап показан светлой точкой и жёлтым кольцом; после отпускания кольцо
  расширяется и затухает.
- Свайп оставляет след со стрелкой направления. След исчезает после отпускания.
- Виртуальное кольцо вокруг дисплея вращается по шагам энкодера. При нажатии
  оно утапливается и подсвечивается, при отпускании возвращается обратно.

Для запуска сразу с отображением действий:

```sh
python3 tools/crowpanel_trace_viewer.py view session.jsonl --show-inputs
```

Перемотка восстанавливает жесты и положение кольца на выбранный момент.
Кнопка **«Сохранить MP4»** учитывает состояние переключателя. При включённых
обозначениях кадр имеет размер 600×600, а изображение дисплея в центре остаётся
480×480. При выключенных сохраняется только дисплей, 480×480.

Для текстового воспроизведения с исходными интервалами:

```sh
python3 tools/crowpanel_trace.py replay session.jsonl --speed 1
```

## Сохранение видео

```sh
python3 tools/crowpanel_trace_viewer.py export session.jsonl \
  --output crowpanel.mp4 --fps 30
```

Для видео с тапами, свайпами и виртуальным кольцом добавьте `--show-inputs`:

```sh
python3 tools/crowpanel_trace_viewer.py export session.jsonl \
  --output crowpanel-inputs.mp4 --fps 30 --show-inputs
```

Для сохранения фрагмента добавьте `--start 5 --end 15` — границы задаются
в секундах от начала журнала. CLI-экспорт перезаписывает указанный MP4.

Видеокадры формируются по времени записанных событий. Частота кадров MP4
не меняет частоту исходной телеметрии и не восстанавливает потерянные события.
Для воспроизведения внешнего вида используйте исходники интерфейса,
соответствующие записанной версии прошивки; её идентификатор сохраняется
в журнале.

## Поток и пропуски

Каждая строка USB-потока начинается с `@CPTRACE `, после которого следует
объект JSON со схемой `crowpanel.trace`, версией `v: 1`, идентификатором
загрузки `boot`, номером `seq` и временем устройства `ms`.

- `meta` описывает прошивку, сборку, хеш ELF и размер экрана.
- `view` содержит полное состояние экрана `view`, подсветку `pressed`
  и дополнительные данные устройства `state`.
- `input` содержит события сенсора и энкодера в объекте `input`.

Полные состояния позволяют начать запись после загрузки устройства.
Счётчик `dropped` и разрывы нумерации показывают пропуски. При медленном
или отключённом компьютере буфер ограничен: устройство отбрасывает записи,
чтобы передача не задерживала управление. Пропущенные касания и состояния
не могут быть восстановлены из журнала.
При пропуске записей незавершённые жесты и нажатие виртуального кольца
сбрасываются до следующего достоверного события ввода.

Журнал воспроизводит программное состояние интерфейса. Артефакты матрицы,
подсветки или физического вывода дисплея в нём не записываются.
