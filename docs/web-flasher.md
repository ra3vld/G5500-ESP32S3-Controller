# Выбор прошивки и установка из браузера

Веб-прошивальщик устанавливает готовые конфигурации G5500 Controller через USB. Компиляция на компьютере и PlatformIO для этого не нужны.

## Выбор конфигурации

1. Откройте [веб-прошивальщик G5500 Controller](https://ra3vld.github.io/G5500-ESP32S3-Controller/).
2. Выберите точную модель платы. Сверьте маркировку, объём Flash и наличие PSRAM. Для ESP32-S3 N16R8 требуется Flash 16 МБ и OPI PSRAM 8 МБ.
3. Для ESP32-S3 выберите дисплей, удалённый пульт или локальный привод. У Waveshare ESP32-S3-ETH доступны две прошивки — с камерой и без неё; Ethernet, MQTT и RS-485 входят в обе. Для обычного ESP32 выберите **Полная · без SPP** либо **Компактная · SPP**; для остальных плат доступна основная прошивка со штатным дисплеем, если он есть. Для CrowPanel с локальным AZ сначала выполните [аппаратную переделку](boards/crowpanel-az.md).
4. На generic ESP32-S3 и CrowPanel выберите набор **MQTT + RS-485** либо **без обоих** одним переключателем. Не предусмотренные профилем сервисы недоступны. Проверьте состав функций, размер и ссылку на подключение выбранной платы.

Расширенный выбор дисплеев и переключатели сервисов доступны для generic ESP32-S3 и CrowPanel; Waveshare использует два фиксированных набора сервисов. У generic ESP32-S3 и CrowPanel MQTT и RS-485 включаются или исключаются только вместе. Переключатель выбирает заранее собранную комбинацию. MQTT выключается вместе с Home Assistant Discovery, RS-485 — вместе с Modbus RTU. Ethernet доступен только платам с поддерживаемым Ethernet-контроллером. Поддерживаемые сервисы и подключённое оборудование настраиваются в веб-интерфейсе контроллера после установки.

Размер приложения и свободное место относятся к разделу приложения, а не ко всей Flash. DRAM и IRAM показывают статическое размещение собранной программы. Свободная RAM во время работы зависит от сервисов, подключений и нагрузки; эти числа не гарантируют быстродействие. Учитывайте [ограничения ESP32-C3 и ESP32-S2](setup/configuration.md#ограничения-esp32-c3-и-esp32-s2).

Если бинарники выбранной версии недоступны, установка заблокирована. Список функций показывает плановый состав по конфигурации профиля; размеры и расход памяти появятся после сборки.

## Запись через USB

1. Используйте браузер с поддержкой Web Serial, например Chrome или Edge на компьютере. Страница должна быть открыта по HTTPS; для локального запуска допускается localhost.
2. Подключите плату USB-кабелем с передачей данных. Для WT32-ETH01 используйте [USB–UART адаптер с логикой 3.3 В](boards/wt32-eth01.md).
3. Закройте монитор порта Arduino IDE, PlatformIO и другие программы, использующие устройство.
4. Подтвердите соответствие платы, Flash, PSRAM и дисплея выбранной конфигурации.
5. Нажмите **Подключить и прошить**, выберите порт и следуйте диалогу ESP Web Tools. Не отключайте питание во время записи.
6. Чтобы сохранить настройки и калибровки, оставьте **Erase device** выключенным. Включение этой опции полностью стирает Flash, включая Wi-Fi, настройки оборудования и калибровку.
7. После перезапуска выполните [первую настройку](quickstart.md). При изменении оборудования или конфигурации проверьте GPIO, тип привода, датчики и калибровку перед движением.

USB-установка записывает загрузчик, таблицу разделов, начальные данные OTA и приложение выбранного профиля. Образы разделены так, чтобы без полного стирания не записывать область NVS с настройками.

Если после прошивки устройство работает с ошибками, повторите установку с **Erase device** — полным стиранием Flash. После этого заново настройте Wi-Fi, оборудование и калибровку. Для [профиля SPP с компактным веб](boards/esp32-spp.md) сначала установите и настройте основную прошивку, затем установите SPP без стирания.

Если устройство не входит в режим загрузки, зажмите **BOOT**, нажмите и отпустите **RESET / EN**, затем отпустите BOOT и повторите подключение. При отсутствии порта проверьте USB-кабель и драйвер USB–UART.

## USB-комплект и обновление по сети

Кнопка **Скачать USB-комплект** сохраняет ZIP с образами, их адресами в `manifest.json`, сведениями о сборке и SHA-256 в `SHA256SUMS`. Используйте адреса своего комплекта: они различаются у семейств ESP32.

`firmware.bin` содержит только приложение. Для [обновления через веб-интерфейс контроллера](maintenance/ota.md) используйте его только при совпадении платы, конфигурации и разметки с установленной прошивкой. Сборки без двух OTA-разделов обновляются через USB.

После успешной записи появится кнопка **Открыть подключения по умолчанию** для установленной платы и профиля. Она откроет инструкцию с распиновкой и доступными схемами. Для generic-дисплеев откроется порядок назначения GPIO. Если прошивка установлена без стирания, сохранённые GPIO могут отличаться от начальных; проверьте их в разделе **Оборудование**.
