# Проверка проекта

## Рефакторинг, 12 октября 2026 года

До разделения модулей сохранён снимок рабочего кода с плавной скоростью. После рефакторинга проходят все **292 проверки ядра**, **231 проверка калибровки, GPIO и NVS**, **11 сетевых тестов** и проверка веб-интерфейса desktop/mobile. Для **1013 команд** ответы исходного и нового ядра сравнивались побайтно и совпали. HTML основной страницы, трёх диагностических страниц и изображение сохранены побайтно.

Новые host-проверки используют подменённые GPIO и хранилище с типизированными ключами. Проверены интерполяция возрастающих и убывающих таблиц, неверные точки, границы, независимость P36/P45, LOW перед включением выходов, снятие противоположного направления перед HIGH, PWM/STOP, ошибка подключения PWM, форматы калибровки 2/3/4, раздельные профили, настройки скорости и touch. Эти проверки не подтверждают физическую запись Flash или электрические уровни на плате.

Оба профиля собраны Arduino CLI и PlatformIO с Arduino-ESP32 3.3.11 и зафиксированными библиотеками. PlatformIO использовал Core 6.1.19 и локальную копию установленной платформы 55.03.311; публичный `platformio.ini` не изменён. Подготовленные скетчи S3/S2 содержат все 36 исходных файлов и соответствующую таблицу разделов; содержимое сверено с канонической папкой.

## Перенос плавной скорости, 12 октября 2026 года

В `G5500_Fork/` перенесены плавный разгон, замедление у цели и торможение перед реверсом для G-800DXA с внешним модулем скорости 0–5 В. Скорости старта, рабочая и у цели, время разгона/торможения и угол замедления доступны через веб/API и сохраняются в NVS. STOP и защиты отключают привод сразу.

Проверены текущие исходники этого репозитория: **292 проверки ядра**, **11 сетевых тестов**, Chromium desktop/mobile с сохранением новых настроек и загрузкой после обновления страницы. Проверки включают разгон/торможение, реверс с паузой 300 мс, границы и переполнение millis, короткую цель, защитные остановки, валидацию параметров и совместимость управления с фиксированной скоростью.

Успешно собраны оба профиля ESP32-S2 и ESP32-S3 через Arduino CLI и PlatformIO. Использован существующий стенд с Arduino-ESP32 3.3.11 и зафиксированными библиотеками; в локальной конфигурации PlatformIO URL заменён на установленный пакет той же версии. Исходный `platformio.ini` сохранён. Журналы Arduino CLI: `build/speed-ramp-s2/compile.log`, `build/speed-ramp-s3/compile.log`; журнал PlatformIO: `build/speed-ramp-pio.log`. Копии исходников Arduino сверены с текущим `G5500_Fork/`, включая таблицы разделов.

| Сборка | Приложение, байт | Статическая RAM, байт |
|---|---:|---:|
| Arduino CLI S3 | 1514546 | 59996 |
| Arduino CLI S2 | 1517575 | 87652 |
| PlatformIO S3 | 1522402 | 60036 |
| PlatformIO S2 | 1525035 | 87724 |

Симулятор интегрирует электронную скорость с шагом до 20 мс; виртуальные 6°/с при полном выходе не описывают конкретный двигатель. Физические уровни 0–5 В, тормозной путь и сохранение новых полей NVS на плате не проверены. Этой версией устройство не прошивалось.

## Ядро управления и сеть

Нужны Python 3 и компилятор C++17:

```sh
./tools/build_native.sh
python3 -m unittest discover -s tests -p test_network.py -v
```

Native-тесты проверяют режимы, подтверждение цели, STOP, приоритет пресетов, диапазоны, готовность калибровки, G-800DXA без EL, тайм-аут движения, паузу реверса, кнопку BOOT, парсеры и API. Сетевые тесты проверяют общий код через localhost UDP, TCP и HTTP.

## Симулятор

```sh
python3 tools/simulator.py
```

Откройте `http://127.0.0.1:8080`. По умолчанию доступны TCP 4533, N1MM UDP 12040, PST UDP 1234 и отчёты N1MM UDP 13010. Параметры запуска перечислены в `python3 tools/simulator.py --help`.

Симулятор исполняет те же C++ парсеры, диспетчер и API, что и прошивка. Он моделирует движение со скоростью 6°/с и использует готовую калибровку. Настройки и пресеты сохраняются только в пределах процесса. NVS, ADC, GPIO, дисплей и аппаратная диагностика не моделируются. `POST /api/sim/step` с `ms=0…3600000` позволяет ускорять проверки таймеров.

Для проверки веб-интерфейса запустите симулятор, затем выполните `npm ci`, `npx playwright install chromium` и `npm run test:web`. Проверяются управление, режимы, предустановки, переключение профилей, мобильная ширина и ошибки JavaScript. Зависимости и параметры описаны в [инструкции сборки](build.md).

## Аппаратная проверка

Сборки и симулятор не подтверждают физический отклик поворотки. Перед эксплуатацией проверить питание, ADC и калибровку, выходы направлений, STOP, реверс, пределы, BOOT, TFT/touch, USB/HC-05 и сохранение настроек после перезагрузки. Для электронной скорости отдельно измерить выход внешнего каскада. Перечень проверок и схемы — в [hardware.md](hardware.md).
