# Проверка проекта

При подготовке репозитория 12 октября 2026 года прошли 222 проверки ядра, все 9 сетевых тестов и проверка веб-интерфейса в Chromium на ширинах 1100 и 390 пикселей.

Обе прошивки собраны Arduino CLI с установленным Arduino-ESP32 3.3.11:

| Профиль | Приложение, байт | Статическая RAM, байт |
|---|---:|---:|
| ESP32-S3 N16R8 | 1 511 026 | 59 956 |
| ESP32-S2, Flash 4 MB | 1 513 923 | 87 612 |

Использован локально установленный core и набор библиотек из [build.md](build.md). Установка зависимостей с нуля на другом компьютере отдельно не проверялась. Для S3 запас приложения следует считать по OTA-разделу `0x640000`, для S2 — по `0x1e0000`, а не по полному объёму Flash.

## Ядро управления и сеть

Нужны Python 3 и компилятор C++17:

```sh
./tools/build_native.sh
python3 -m unittest discover -s tests -p test_network.py -v
```

Native-тесты проверяют режимы, подтверждение цели, STOP, приоритет пресетов, диапазоны, готовность калибровки, G-800DXA без EL, тайм-аут движения, паузу реверса, кнопку BOOT, парсеры и API. Сетевые тесты проверяют общий код через localhost UDP, TCP и HTTP.

## Симулятор

```sh
python3 tools/simulator.py
```

Откройте `http://127.0.0.1:8080`. По умолчанию доступны TCP 4533, N1MM UDP 12040, PST UDP 1234 и отчёты N1MM UDP 13010. Параметры запуска перечислены в `python3 tools/simulator.py --help`.

Симулятор исполняет те же C++ парсеры, диспетчер и API, что и прошивка. Он моделирует движение со скоростью 6°/с и использует готовую калибровку. Настройки и пресеты сохраняются только в пределах процесса. NVS, ADC, GPIO, дисплей и аппаратная диагностика не моделируются. `POST /api/sim/step` с `ms=0…3600000` позволяет ускорять проверки таймеров.

Для проверки веб-интерфейса запустите симулятор, затем выполните `npm ci`, `npx playwright install chromium` и `npm run test:web`. Проверяются управление, режимы, предустановки, переключение профилей, мобильная ширина и ошибки JavaScript. Зависимости и параметры описаны в [инструкции сборки](build.md).

## Аппаратная проверка

Сборки и симулятор не подтверждают физический отклик поворотки. Перед эксплуатацией проверить питание, ADC и калибровку, выходы направлений, STOP, реверс, пределы, BOOT, TFT/touch, USB/HC-05 и сохранение настроек после перезагрузки. Для электронной скорости отдельно измерить выход внешнего каскада. Перечень проверок и схемы — в [hardware.md](hardware.md).
