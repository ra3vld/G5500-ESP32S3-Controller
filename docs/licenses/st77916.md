# Таблицы инициализации ST77916

`G5500_Fork/st77916_init.hpp` содержит значения регистров из официального примера [Waveshare 1.85inch Touch LCD Module](https://github.com/waveshareteam/1.85inch-Touch-LCD-Module), файлы `main/LCD_Driver/ST77916.c` и `main/LCD_Driver/esp_lcd_st77916/esp_lcd_st77916.c` в примере `1.85-S3-test`.

Исходная таблица драйвера: Copyright 2023 Espressif Systems (Shanghai) CO LTD, [Apache License 2.0](st77916-Apache-2.0.txt). Значения сохранены в компактных C++-массивах; код транспорта и интеграции с интерфейсом проекта написан отдельно.
