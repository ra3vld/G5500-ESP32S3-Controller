# G5500 Controller

Прошивка контроллера антенных поворотных устройств Yaesu G-5500, G-800DXA и независимых DC-приводов. Поддерживает ESP32 WROOM/WROVER, ESP32-S3, ESP32-S2 и круглый пульт CrowPanel 2.1.

## Возможности

- Азимут P36/P45 или [произвольный диапазон](docs/az-range.md) с ходом 1…3600° и смещением начала в обе стороны; элевация 0…180° или собственный произвольный диапазон с независимыми калибровками у двухосевой поворотки.
- Управление штатным блоком Yaesu либо независимыми двигателями через PWM, в том числе два модуля IBT-2/BTS7960.
- Плавный разгон, замедление у цели и торможение перед реверсом при управлении скоростью. Для G-800DXA нужен внешний модуль 0–5 В.
- Ручной режим с подтверждением внешних целей, автоматический режим и «Авто 1 ч».
- Четыре редактируемые предустановки для каждого профиля поворотки.
- [OTA из браузера и Arduino IDE](docs/ota.md) с автоматической проверкой flash и разделов.
- Веб-интерфейс, калибровка, диагностика и необязательный дисплей ILI9341/XPT2046 или параллельный LCD1602.
- GS-232 через UART0 и Bluetooth; rotctld и GS-232 через TCP 4533; прямой UDP для N1MM Logger+, UR5EQF и 5MContest.
- [HUD](docs/hud.md): удалённые пульты и несколько повороток по Wi-Fi или UART. [CrowPanel 2.1](docs/crowpanel-21.md) работает как HUD или с имитацией привода.

В ручном режиме числовая цель от логгера по умолчанию ожидает подтверждения. В настройках можно независимо включить автоследование для N1MM UDP, PstRotator UDP, GS-232 и rotctld. Команды направления и STOP выполняются сразу, кроме ограничений активной предустановки, описанных в [инструкции управления](docs/usage.md#предустановки-и-профили). Для наведения реальной поворотки нужна калибровка соответствующей оси; в имитации она не требуется.

## Начало работы

1. Выберите плату и схему подключения в [аппаратной инструкции](docs/hardware.md).
2. Настройте [build_config.hpp](G5500_Fork/build_config.hpp) по [таблице параметров](docs/configuration.md). По умолчанию дисплей и Bluetooth выключены, интерфейс привода — YAESU. Имитация включена по умолчанию только на CrowPanel.
3. Соберите прошивку для своей платы по [инструкции сборки](docs/build.md).
4. После первого запуска подключитесь к сети `G5500-Rotator-XXXXXX` и откройте `http://192.168.4.1`. В настройках задайте Wi-Fi, пароль точки доступа и модель поворотки. Для удалённого пульта выберите роль HUD.
5. Для реального привода проверьте подключение и направления, выполните калибровку, затем настройте логгер. Для HUD калибруется контроллер возле двигателя.

Arduino IDE: откройте **[G5500_Fork/G5500_Fork.ino](G5500_Fork/G5500_Fork.ino)** вместе с его папкой. Плату и Partition Scheme выбирайте по [инструкции](docs/build.md#arduino-ide-2x).

PlatformIO, примеры сборки без дисплея:

```sh
pio run -e esp32s3_n16r8
pio run -e esp32_4mb
pio run -e esp32s2_mini
```

Для выбора дисплея, Bluetooth и силового интерфейса используйте общий скрипт:

```sh
python3 tools/build_platformio.py --env esp32s2_mini --display lcd --bluetooth 0 --drive bts7960
```
