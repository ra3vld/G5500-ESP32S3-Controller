# G5500 Controller

Прошивка контроллера антенных поворотных устройств Yaesu G-5500 и G-800DXA для ESP32-S3 и ESP32-S2. Форк проекта [UA1CFM/G5500-ESP32S3-Controller](https://github.com/ua1cfm/G5500-ESP32S3-Controller), основанный на v1.6.23 P36/P45 SAFE TCP COLOR.

## Возможности

- G-5500: азимут и угол места; G-800DXA: азимут с диапазоном 360° или 450°.
- Ручной режим с подтверждением внешней цели, автоматический режим и «Авто 1 ч».
- Подтверждение цели кнопкой BOOT или из веб-интерфейса.
- Четыре редактируемые предустановки для каждого профиля.
- Прямое управление из N1MM Logger+, UR5EQF и 5MContest по UDP.
- GS-232 через UART0 и HC-05; rotctld и GS-232 через TCP 4533.
- Веб-интерфейс, TFT ILI9341 320×240 с XPT2046, калибровка и диагностика.
- Опциональная регулировка скорости G-800DXA через внешний каскад 0–5 В: плавный разгон, замедление у цели и торможение перед реверсом; скорости и параметры плавности задаются в настройках.

В ручном режиме числовая цель от логгера ожидает подтверждения. Команды направления и STOP выполняются сразу. Для наведения на числовую цель нужна калибровка соответствующей оси.

## Начало работы

Проект для Arduino IDE: **[G5500_Fork/G5500_Fork.ino](G5500_Fork/G5500_Fork.ino)**. Откройте этот файл вместе с его папкой. Скетч содержит `setup()` и `loop()`; Arduino IDE автоматически собирает реализацию из соседних `.cpp` и показывает файлы проекта во вкладках.

Для сборки через PlatformIO:

```sh
pio run -e esp32s3_n16r8
# ESP32-S2 с Flash 4 MB:
pio run -e esp32s2_4mb
```

После первого запуска подключитесь к точке доступа `G5500-Rotator` и откройте `http://192.168.4.1`. В настройках задайте Wi-Fi, пароль точки доступа и профиль поворотки. Затем выполните калибровку и настройте логгер.
