# G5500 Controller

Прошивка контроллера антенных поворотных устройств Yaesu G-5500, G-800DXA или прямое PWM управление двигателями с поддержкой ESP32 и ESP32-S3/S2. Форк проекта [UA1CFM/G5500-ESP32S3-Controller](https://github.com/ua1cfm/G5500-ESP32S3-Controller), основанный на v1.6.23 P36/P45 SAFE TCP COLOR, с переносом возможностей веток до v1.6.29.

## Возможности

- G-5500, G-800DXA, PWM с диапазоном 360° или 450°.
- Регулировка скорости G-800DXA 0–5 В: плавный разгон, замедление у цели и торможение перед реверсом; скорости и параметры плавности.
- GS-232 через UART0 и Bluetooth (встроенный SPP на ESP32, HC-05 на S2/S3); rotctld и GS-232 через TCP 4533.
- Прямое управление из программ поддерживающих протоколы: GS-232, GS-232 UDP, rotctld, PST Rotator (N1MM Logger+, UR5EQF и 5MContest, TR4W, Not1MM и др.).
- Автоматический режим, ручной режим с подтверждением старта задачи кнопкой, «Авто 1 ч».
- Подтверждение цели в ручном режиме пользовательской кнопкой на настраиваемом GPIO или из веб-интерфейса.
- Четыре редактируемые предустановки для каждого профиля.
- Веб-интерфейс, опциональные TFT ILI9341/XPT2046 или параллельный LCD1602, калибровка и диагностика.
- Профили ESP32 WROOM/WROVER, ESP32 S3 N16R8, ESP32 S2.

В ручном режиме числовая цель от логгера ожидает подтверждения. Команды направления и STOP выполняются сразу. Для наведения на числовую цель нужна калибровка соответствующей оси.

## Начало работы

Проект для Arduino IDE: **[G5500_Fork/G5500_Fork.ino](G5500_Fork/G5500_Fork.ino)**. Откройте этот файл вместе с его папкой. Скетч содержит `setup()` и `loop()`; Arduino IDE автоматически собирает реализацию из соседних `.cpp` и показывает файлы проекта во вкладках. Плату и Partition Scheme выбирайте в IDE; для ESP32 4 МБ с Bluetooth — **Huge APP (3MB No OTA/1MB SPIFFS)**.

Для сборки через PlatformIO:

```sh
pio run -e esp32s3_n16r8
# Классический ESP32 WROOM/WROVER, Flash от 4 MB:
pio run -e esp32_4mb
# ESP32-S2 с Flash 4 MB:
pio run -e esp32s2_4mb
```

Аппаратные параметры — в [build_config.hpp](G5500_Fork/build_config.hpp). По умолчанию: дисплей NONE, Bluetooth включён, интерфейс YAESU. ESP32 использует встроенный SPP без HC-05; S2/S3 — внешний HC-05. Для выбора зависимостей по конфигурации:

```sh
python3 tools/build_platformio.py --env esp32s2_mini --display lcd --bluetooth 0 --drive bts7960
# Arduino CLI:
DISPLAY_KIND=2 BLUETOOTH_ENABLED=0 DRIVE_INTERFACE=2 ./tools/build_arduino.sh s2-mini
```

[Классический ESP32 и встроенный Bluetooth](docs/classic-esp32.md), [профили, распиновка и кнопка](docs/configuration.md), [два IBT-2 без внешнего буфера](docs/hardware/independent-pwm-bts7960.md), [изолированное управление IBT-2](docs/hardware/independent-pwm-bts7960-isolated.md), [инструкция сборки](docs/build.md). Порог 5° задаёт момент выключения; физическая точность и выбег зависят от механики.

После первого запуска подключитесь к точке доступа `G5500-Rotator` и откройте `http://192.168.4.1`. В настройках задайте Wi-Fi, пароль точки доступа и профиль поворотки. Затем выполните калибровку и настройте логгер.
