# G5500 Controller

Прошивка контроллера антенных поворотных устройств Yaesu G-5500, G-800DXA и независимых DC-приводов. Поддерживает ESP32 WROOM/WROVER, ESP32-S3, ESP32-S2 и CrowPanel 2.1.

## Начало работы

Начните с [первого запуска](docs/quickstart.md): выбор платы и подключения → сборка и USB-прошивка → настройка оборудования → калибровка → управление.

Для ESP32-S3 DevKitC-1 N16R8 без дисплея:

```sh
pio run -e esp32s3_n16r8
```

Это только сборка. [Запись через USB](docs/build.md#первая-прошивка-через-usb), [выбор других плат](docs/configuration.md#выбор-конфигурации), [вся документация](docs/index.md).

## Возможности

- AZ и EL с независимой калибровкой, стандартными или произвольными диапазонами.
- Штатные блоки Yaesu, отдельные PWM-приводы и BTS7960 / IBT-2.
- Простой регулятор или каскадный ПИД, страгивание, удержание и автотюн.
- Веб-управление, предустановки, кнопки направлений и аналоговый джойстик.
- Дисплеи ILI9341/XPT2046, LCD1602 и CrowPanel 2.1; удалённые пульты HUD.
- GS-232, rotctld, N1MM и PstRotator UDP; HTTP, WebSocket и командный API.
- Настройка GPIO без пересборки, имитация движения, обновление по Wi-Fi при подходящей разметке Flash.

Для реального числового наведения нужна калибровка. В ручном режиме внешняя цель по умолчанию ждёт подтверждения; автоследование включается отдельно для каждого протокола.
